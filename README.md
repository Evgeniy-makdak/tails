# Хвостик (TAILIO)

Мобильное приложение для хозяев собак и кошек: живой GPS-ошейник, статус «всё хорошо», карта, геозоны, здоровье, SOS и ИИ-помощник **Хвостик**. Интерфейс на русском языке, дизайн по макету Figma «Проект „Хвостик“ — Фадейкина А.Д.».

Один и тот же код запускается:

- в **браузере на компьютере** — в рамке смартфона 390×844, как на реальном iPhone;
- на **iPhone / iPad** (в перспективе публикация в **App Store**);
- на **Android** (в перспективе публикация в **Google Play**).

Переписывать проект под каждую платформу не нужно: это **Expo (React Native)** с веб-превью.

---

## Зачем это приложение

Хозяин открывает «Хвостик» и сразу видит, в порядке ли питомец: дома ли он, спокоен ли, заряжен ли ошейник. Если питомец вышел из безопасной зоны или пропал — включается SOS: последняя точка на карте, маршрут, свет/звук ошейника, звонок в поддержку.

Сейчас в репозитории — рабочий интерактивный прототип. Аккаунты и питомцы хранятся **локально в браузере** (без сервера). Демо-пользователь с Персиком: **`demo@tailio.app`**. Живой GPS, настоящая почта и оплата сторов подключаются на следующем этапе, **без смены архитектуры**.

## Что уже есть в прототипе

### Первый запуск

1. Сплэш **TAILIO**
2. Приветственный слоган
3. Регистрация / вход по почте
4. Код из письма (для демо введите **`111111`**)
5. Соглашение
6. Возможности приложения
7. Имя хозяина
8. Карточка питомца
9. Подключение ошейника (можно пропустить)

### Главные вкладки

| Вкладка | Содержание |
| --- | --- |
| **Главная** | Имя питомца, статус, выбор питомца из списка, переход в чат с ИИ |
| **Карта** | Live-точка, зум, карточка питомца с полями по краям экрана, экстренный поиск, геозоны, история |
| **Здоровье** | Показатели и детали |
| **Профиль** | Хозяин, питомцы, документы |

Дополнительно: уведомления, геозоны (безопасные / опасные), создание места, история перемещений, SOS-режим.

## Как проверить на компьютере (экран как у смартфона)

На вебе приложение **не растягивается на весь монитор**. Оно рисуется внутри чёрной рамки телефона **390×844** (как iPhone 14/15), с «островком» сверху. Так удобно сверять вёрстку с Figma, не ставя симулятор.

### 1. Что нужно один раз

- [Node.js](https://nodejs.org/) **18 или 20** (на этой машине проверено с Node 21; для будущих версий Expo лучше 20 LTS или 22+)
- npm (идёт вместе с Node)
- VS Code или Cursor

### 2. Откройте папку проекта

В VS Code / Cursor: **File → Open Folder** и выберите эту папку (`tail`).

### 3. Команды в терминале VS Code

Откройте терминал:

- **macOS:** `` Ctrl+` `` или меню **Terminal → New Terminal**
- **Windows:** `` Ctrl+` `` или **View → Terminal**

Терминал должен показывать путь к папке проекта. Если нет:

```bash
cd путь/к/папке/tail
```

Установка зависимостей (только после клонирования или если нет папки `node_modules`):

```bash
npm install
```

Запуск веб-превью:

```bash
npx expo start --web --port 8081
```

Либо короче, тем же скриптом из `package.json`:

```bash
npm run web
```

Когда Metro напишет, что сервер готов, откройте в браузере:

**http://localhost:8081**

Вы увидите серый фон и по центру — телефон с приложением. Если стили «залипли» после правок, сделайте жёсткое обновление: **Cmd+Shift+R** (macOS) или **Ctrl+Shift+R** (Windows).

Остановить сервер: в том же терминале **Ctrl+C**.

### 4. Если порт 8081 занят

```bash
npx expo start --web --port 8082
```

и откройте `http://localhost:8082`.

### 5. Демо-вход

Регистрация и вход различаются. Новый email проходит онбординг и сохраняет **своего** питомца. Уже занятый email при регистрации не подойдёт — нужно войти.

- Код из «письма» (и для регистрации, и для входа): введите вручную **`111111`**. Другой код — ошибка, ячейки очищаются.
- Готовый аккаунт с Персиком: **`demo@tailio.app`**, код **`111111`**.

### 6. Как удалить тестовых пользователей (кроме Персика)

Данные аккаунтов лежат в браузере, ключ **`hvostik-app-v5`**. После очистки останется только дефолтный демо-аккаунт `demo@tailio.app` с Персиком — его приложение создаёт заново при загрузке.

1. Откройте превью: **http://localhost:8081**
2. Откройте DevTools: **Cmd+Option+I** (macOS) или **F12** / **Ctrl+Shift+I** (Windows)
3. Вкладка **Console**
4. Если консоль блокирует вставку, **сначала вручную наберите** `allow pasting` и нажмите Enter. Без этой фразы Chrome часто не даёт вставить код из буфера.
5. Затем вставьте и выполните:

```js
localStorage.removeItem('hvostik-app-v5');
location.reload();
```

Либо: DevTools → **Application** → **Local Storage** → `http://localhost:8081` → удалите ключ `hvostik-app-v5` → жёсткое обновление **Cmd+Shift+R** (macOS) / **Ctrl+Shift+R** (Windows).

После сброса войдите снова как `demo@tailio.app`. Все остальные тестовые почты и их питомцы исчезнут.

## Сборка в App Store и Google Play

Проект изначально заточен под магазины приложений: это не сайт, который потом «перепишут под мобилки». Один исходник → три цели.

| Платформа | Как попадёт в магазин |
| --- | --- |
| **iOS / App Store** | Сборка через [EAS Build](https://docs.expo.dev/build/introduction/), затем `eas submit` в App Store Connect. Нужны Apple Developer Program и bundle id `com.hvostik.app`. |
| **Android / Google Play** | Сборка **AAB** (Android App Bundle) профилем `production` в `eas.json`, загрузка в Play Console. Пакет: `com.hvostik.app`. |
| **Проверка на телефоне до магазина** | Профиль `preview`: Android APK для внутренней раздачи; iOS — internal distribution / TestFlight. |

Конфиг сборок уже лежит в `eas.json`:

- `development` — dev-клиент для разработки на устройстве;
- `preview` — внутренняя проверка (APK на Android);
- `production` — релиз: AAB для Google Play, iOS-архив для App Store.

Типовой релиз (когда будет Apple/Google-аккаунт):

```bash
npm install -g eas-cli
eas login
eas build --platform ios --profile production
eas build --platform android --profile production
eas submit --platform ios --profile production
eas submit --platform android --profile production
```

Нативные папки `ios/` и `android/` в git не хранятся: их генерирует Expo / EAS в облаке. Локальный прогон на симуляторе:

```bash
npx expo start --ios
npx expo start --android
```

Для iOS нужен Mac с Xcode, для Android — Android Studio / эмулятор.

## Текущий статус

Прототип для согласования UI с макетом Figma и для демонстрации сценариев (регистрация, вход, главная, карта, геозоны, SOS). Аккаунты локальные, до ~10 тестовых пользователей на одном устройстве. Следующие шаги: пиксельное соответствие макету, живой GPS, реальная почта/OTP, подготовка релизов в App Store и Google Play.
